Md Mosaddek Billah - Portfolio Website (GitHub Pages গাইড)

এই zip-এ আছে:
- index.html : তোমার পোর্টফোলিও ওয়েবসাইট (ছবিসহ সব এক ফাইলে)
- README.txt : এই গাইড

GitHub-এ লাইভ করার ধাপ (মোবাইল থেকেই হবে):
1. github.com-এ লগইন করো
2. নতুন Repository বানাও, নাম দাও: mosaddek-portfolio (Public রাখো)
3. Repository-তে "Add file" > "Upload files" চেপে index.html ফাইলটা আপলোড করো, তারপর Commit করো
4. Repository-র Settings > Pages-এ যাও
5. Source: "Deploy from a branch", Branch: main, Folder: / (root) বেছে Save করো
6. ১-২ মিনিট পর তোমার সাইট লাইভ হবে এই ঠিকানায়:
   https://তোমার-ইউজারনেম.github.io/mosaddek-portfolio/

নোট:
- index.html-এর নাম বদলিও না, GitHub Pages এই নামটাই খোঁজে
- ফোন নম্বর আর ইমেইল সাইটে প্রকাশ্য আছে (তুমি নিজে দিয়েছ)
- পরে কিছু বদলাতে চাইলে Muse-কে বলো, নতুন index.html বানিয়ে দেবে
